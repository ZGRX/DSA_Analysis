## 项目概述

本项目将原 `DSA_Analysis_GUI_v5.m` (3443行) 单一文件重构为模块化架构，提高代码可维护性、可扩展性和团队协作效率。

**原始文件:** `DSA_Analysis_GUI_v5.m` (3443 行)  
**重构入口:** `DSA_Analysis_GUI_Refactored.m` (67 行)  
**模块总数:** 36 个独立文件  
**总代码行数:** ~2000 行 (模块化后代码更清晰简洁)

---


## 快速开始

```matlab
% 添加模块路径并启动系统
addpath(genpath('modules'))
DSA_Analysis_GUI_Refactored
```

**推荐工作流程:**
1. 点击 **📁 文件管理器** 按钮打开文件浏览器
2. 在左侧导入DICOM文件，点击 **⚡加载到系统**
3. 在主界面进行ROI分析、参数计算
4. 回到文件管理器，点击 **📤导出结果**
5. 右侧Results目录自动保存所有分析成果

### 二、正确的操作顺序（关键！）

#### **标准临床工作流 (Standard Clinical Workflow)**

```
【第1步】 打开文件 (File Manager)
   └─ 操作: 左侧选择患者DICOM文件 → 点击"⚡加载到系统"
   └─ 结果: DSA原始图像序列加载到主窗口
   
【第2步】 一键生成 CC-DSA (推荐) 或 传统ROI分析 (可选)  
   ├─ 推荐路径: 一键生成 CC-DSA (Full-Pixel)
   │  └─ 自动提取全脑TDC + 计算血流参数 (3-5秒)
   │
   └─ 可选路径: 传统 ROI 分析
      └─ 手动放置12个ROI点 → 提取 TDC 曲线
   
【第3步】 像素参数图
   └─ 自动扫描全脑512×512像素，计算每像素的TTP和AUC
   └─ 耗时: ~10秒，但仅需做一次
   └─ 这是后续所有诊断的基础！
   
【第4步】 组织分类 (Tissue) (基础诊断)
   └─ 三分类: 正常 / 半暗带 / 梗死核心
   └─ 快速了解患者的梗死情况
   
【第5步】 [NEW] 四象限风险分层 (医学标准诊断) ⭐⭐⭐
   └─ 四分类: 正常(绿) / 半暗带(黄) / 梗死核心(红) / 高转流(橙)
   └─ 核心价值: 计算 Mismatch Ratio，决定是否做血栓切除
   └─ 如果 Mismatch > 1.8 → 强烈推荐血栓切除
   
【第6步】 [NEW] 病灶自动标注 (精准定位) ⭐⭐⭐
   └─ 自动检测所有异常病灶
   └─ 按严重程度排序 (L1最危险 → L2 → L3...)
   └─ 医生点击列表，地图自动闪烁高亮该病灶
   
【第7步】 导出报告 (Export)
   └─ 保存所有分析结果为Excel/MAT/CSV
   └─ 自动保存到 PatientData/[PatientID]/Results
   
【可选】 术前术后对比分析
   └─ 加载术后DSA数据，对比灌注参数改善情况
```

### 四、v3.1 新增功能亮点

#### **[NEW] 四象限风险分层** (分析 > 结果与对比 > 绿色按钮)

**背景**: 传统DSA分析只显示参数，医生需要自己判断是否该做血栓切除

**创新**: 
- ✅ 自动四分类: 正常(绿) / 半暗带(黄) / 梗死核心(红) / 高转流(橙)
- ✅ 计算 **Mismatch Ratio = Penumbra / Core**
- ✅ 直接给出医学建议:
  - Mismatch > 1.8 → **强烈推荐血栓切除** ✓
  - Mismatch 1.0-1.8 → **考虑血栓切除**
  - Mismatch < 1.0 → **切除价值有限** ✗

**临床价值**: 帮助医生在3分钟内做出最重要的治疗决策

---

#### **[NEW] 病灶自动标注** (分析 > 结果与对比 > 蓝色按钮)

**背景**: 传统方法医生需要逐像素扫描，手动标记所有异常区域

**创新**:
- ✅ 自动检测所有病灶区域 (Connected Component Analysis)
- ✅ 计算严重程度评分 (0-100分)
- ✅ 自动排序: L1 (最危险) → L2 → L3...
- ✅ 交互式导航: 点击病灶列表，地图自动闪烁标记
- ✅ 详细统计: 面积、核心百分比、平均TTP/AUC

**临床价值**: 医生不需要手动扫描，所有病灶自动显示和排序！

### 五、常见错误及排查

| 错误现象 | 原因 | 解决方案 |
|--------|------|--------|
| 点"一键生成CC-DSA"后没反应 | 未导入DSA数据 | 先点"打开文件"导入DICOM |
| "像素参数图"显示全黑 | TTP值计算异常 | 确保导入的DICOM文件正确 |
| "组织分类"报错 | 未计算参数图 | 先点"像素参数图"按钮 |
| "四象限风险分层"闪退 | 字体兼容性问题(已修复) | 更新到最新版本(v3.1.1) |
| "病灶自动标注"无反应 | 字体兼容性问题(已修复) | 重启MATLAB后重试 |
| 导出报告时找不到文件夹 | Results目录不存在 | 系统会自动创建，方便无需担心 |

## 灌注参数

系统计算以下 **11个参数** × **4个脑叶**:

| 参数 | 说明 | 单位 |
|------|------|:----:|
| **TMAX** | 峰值时间 | s |
| **MTT** | 平均通过时间 | s |
| **TU** | 上升时间 | s |
| **TD** | 下降时间 | s |
| **1/2TMAX** | 半峰值时间 | s |
| **AUC** | 曲线下面积 | SI·s |
| **AUCbefore** | 峰值前面积 | SI·s |
| **AUCratio** | 面积比 | - |
| **MS** | 最大斜率 | SI/s |
| **AFS** | 平均斜率 | SI/s |
| **CBF** | 脑血流量 | SI |
